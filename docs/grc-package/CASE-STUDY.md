# Case Study — Governance, Risk & Compliance (Authorization / ATO)

**Reuben Osilaja · GRC & Authorization Lead**
*Enterprise, cloud, and federal systems · NIST RMF · 800-53 · FedRAMP · FISMA*

---

### Challenge

Systems were waiting too long for their Authorization to Operate (ATO). Documentation was produced ad hoc — every System Security Plan looked different, evidence was gathered by hand at audit time, and Plans of Action & Milestones (POA&M) were tracked inconsistently. The result was slow authorization timelines, avoidable audit findings, and a compliance posture that was hard to sustain between assessments. The organization needed authorization to become **repeatable and evidence-driven**, not a one-off scramble.

### Approach

I built authorization and compliance into a repeatable program — effectively **"ATO-as-a-Service"** — so security work translated directly into audit-ready evidence:

- **Standardized documentation** — templated SSPs, Security Assessment Reports (SAR), and POA&Ms so every system started from a consistent, control-mapped baseline.
- **Security control assessments** — evaluated NIST 800-53 control implementation across the system portfolio and produced defensible assessment reports.
- **Continuous monitoring (ConMon)** — established a monitoring cadence and control-mapped evidence pipeline so authorization was sustained, not just achieved.
- **Automated evidence collection** — reduced the manual effort of gathering audit artifacts, shortening reporting cycles.
- **Cross-team translation** — converted technical risk into compliance language (control gaps, residual risk, POA&M items) for audit, ATO, and leadership consumption.

### Tools & Frameworks

NIST Risk Management Framework (RMF) · NIST 800-53 Rev. 4/5 · FedRAMP · FISMA · ISO 27001 · Qualys VMDR · ServiceNow (GRC & workflow) · AWS / hybrid cloud

### Outcomes

- **Authorization timelines reduced ~25%** through structured SSPs and standardized documentation.
- **Audit findings reduced ~40%** via consistent control implementation and evidence.
- **Reporting time cut ~30%** through automated evidence collection, enabling faster POA&M closure.
- **Authorization support scaled** across 20+ federal systems while strengthening audit readiness.
