Program 03

Container Image Hardening — Remediation Evidence

Scan, fix, and verify on real public images: rebasing nginx from an end-of-support Debian 11 base to current Alpine eliminated all 30 critical findings, verified by Trivy rescan.

30 → 0 critical−81% findings (921 → 177)
  • Scan — baseline OS and package CVEs by severity (NIST 800-53 RA-5).
  • Root cause — most findings traced to an EOL base image, so one fix cleared hundreds of CVEs.
  • Remediate & verify — rebase, rebuild, and rescan to 0 critical before closing (SI-2, CA-7).
